# Machine-Problem-ITE193-MP5

## Overview

The ITE193 Student Account Management System with Sari-Sari Store is a web-based application developed as a requirement for Event Driven Programming.

The system provides student account management and sari-sari store operations including inventory monitoring, shopping cart management, order processing, and database integration using MySQL.

## Features

### User Management
- User Registration
- User Login and Logout
- Change Password
- User Profile Retrieval

### Inventory Management
- Add New Product
- Edit Product Information
- Delete Product
- Add Stock Quantity
- Search Products
- View Product Inventory

### Shopping Cart
- Add to Cart
- Remove Items
- Clear Cart
- Automatic Total Calculation

### Order Processing
- Checkout Products
- Save Orders
- Order History
- Automatic Stock Deduction

### Database Integration
- MySQL Database
- Persistent Data Storage
- CRUD Operations
